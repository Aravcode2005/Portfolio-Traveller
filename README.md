# Arav Gupta — Volunteer Travel Portfolio

A fast, responsive, static portfolio site showcasing photography, videos, AI automation, web development, writing, content creation and martial arts. Poetry can be added later without delaying launch.

## Run locally

Run `python3 -m http.server 3000` inside this directory and visit `http://localhost:3000`.

## Deploy to Vercel

Import this folder as a new project from GitHub, or run `npx vercel` from the folder after authenticating. Choose **Other** as framework, no build command, output directory `.`. `vercel.json` configures this as a static site.

## Before sharing publicly

- Add an approved portrait and contact email.
- Review every description for accuracy and permission to represent the work.
- Check that the game link is live (the current link is an EC2 IP address).
- Confirm which of the two Instagram links matches each video edit.
- Confirm the black-belt certificate and whether 'fitness training' should be described as coaching experience.
- Video previews are still images, not redistributed movie/anime footage. Open Instagram links for published reels.
- Add original poems and a technical documentation example when ready.

## Editing

- Update project cards and external links in `index.html`.
- Replace photos in `assets/` and match the same filenames, or update markup.
- Theme variables are at the top of `style.css`.
